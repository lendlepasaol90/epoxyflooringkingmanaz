# Epoxy Flooring Kingman AZ

Source for epoxyflooringkingmanaz.com. Pages are generated by `src/build.mjs` into `public/` and served by a Cloudflare Worker (`worker/index.js`), which also receives the estimate form at `/api/lead`.

## Pages

- `/`
- `/garage-coatings/`
- `/residential-floor-coatings/`
- `/flake-epoxy/`
- `/polyaspartic/`
- `/polyurea/`
- `/patio-coatings/`
- `/shop-and-commercial-floors/`
- `/warehouse-floors/`
- `/about/`
- `/service-area/`
- `/estimate/`
- `/privacy/`

Service pages live in `src/content/services/` (one file per page, registered in `src/site.mjs`).

## Working on it
